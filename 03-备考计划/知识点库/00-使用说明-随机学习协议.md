# 知识点库 · 随机学习操作协议

> 本协议取代"日程表式计划"。你有完全的单日自由：想学哪个学哪个、想串联就串联、想深挖就深挖。
> 代价是三道约束：**可学池（依赖）→ 优先级配额 → 阶段覆盖率红线**，全部以"周"和"阶段"为单位检查，不管你某一天在干嘛。
> 库存：数学一 121 个知识点（A级73）· 408 共 122 个（A级63）· 合计 **243 个原子知识点**。

## 一、状态机（每个知识点的生命周期）

```
⬜ 未学 → 📖 已理解 → ✍️ 已刷题 → ✅ 已掌握
                ↑                    ↓
                └──── 🔁 待复习 ←────┘（遗忘复查失败回退）
```

| 状态 | 达成标准（自己诚实验证） |
|---|---|
| ⬜ 未学 | 没碰过 |
| 📖 已理解 | 看完课/书该节，能不看资料复述该知识点的定义、作用、典型题型思路；**并通过冒烟测试**（见下方V3规则） |
| ✍️ 已刷题 | 该知识点题包完成且**正确率≥70%**；错题已录入错题本 |
| ✅ 已掌握 | 通过周检验抽讲（费曼）或该知识点在套卷中做对 |
| 🔁 待复习 | 距上次✅超过复查周期，或复查失败 |
| ⚠️ 疑点（附注状态） | 冒烟测试3题错2+；挂在本周回炉队列，不阻塞学新点 |

**V3核心规则（2026-10-06修订，替代原"📖→✍️不跨周"）**：
- **题包不跟随理解**——理解期📖自由跑，题包集中到刷题期（2027年2月中~3月）统一清账
- **冒烟测试必须跟随**——每个点到📖的同时，限时10分钟做该题包**前2~3道基础题**（数学：1800该节选择题前3道；408：王道该节选择题前2道），3对2即通过。冒烟不是练熟（那是刷题期的事），是防"假懂"的唯一及时反馈——如同写完模块跑个冒烟用例
- 冒烟不过 → 标⚠️疑点，周检验优先消化（重看该节+再做1题）；疑点**不阻塞**继续学新点
- **回退保险丝**：疑点率连续两周>15% → 说明理解质量出系统性问题，回退V2同步模式（题包跟随）

## 二、每日操作（三步，2分钟决策）

1. **开池**：打开两份清单，扫一眼今天的"可学池"（见第三节定义）里有哪些 ⬜ 或 🔁
2. **随心选**：按当天兴趣选 1~3 个（串联几个相关的、或单点深挖都行；⚡标记的点是你消耗快的，A/B/C见配额规则）
3. **离场登记**：今天推进到什么状态就改什么状态。深挖过头的（超45min时间盒）记《深挖清单》

不做任何"今天应该学什么"的预设。唯一建议：**每天至少摸一次数学**（哪怕只是复习🔁池里的旧点），数学手感断两天就凉。

## 三、可学池定义（依赖约束，防止随机撞墙）

一个 ⬜ 知识点"可学"当且仅当：**清单中"前置"列引用的ID全部达到 📖 及以上**。

示例：
- M52（对称性技巧）前置 M42-M49 → 多元积分学了一大半才能开
- N23（拥塞控制）前置 N21 → 可学
- 无前置标注的知识点（如P01、D01、L03）任何时候都可学

**串联学习的加成**：清单里标了跨科联动对（408清单末尾6组），当你随机抽到的点恰好有联动伙伴时，优先串联学（例如抽到 C15 虚拟存储就顺手看 O17），一次理解、两科入库，还满足你的串联偏好。

## 四、优先级配额（防失衡·第一道约束）

随机游走的自然风险是"C级甜点吃太多、A级硬骨头没人啃"。规则：

1. **A级知识点占你每周新学（📖）数量的比例 ≥ 60%**
2. C级知识点每周新学 ≤ 2 个（当调剂点心，比如曲率、傅里叶、SPOOLing 这类有趣的小点）
3. B级自由填充

执行方式很简单：周日晚盘点时数一下本周 📖 新增里 A/B/C 各几个，不满足配额→下周优先消耗A级池。

## 六、遗忘复查（🔁机制）

- 每个到达 ✅ 的知识点自动排期：**7天后第一次复查、30天第二次、90天第三次**
- 复查方式（递减成本）：一次问自己"这题怎么下手"→ 抽1道错题本里该点的题→ 套卷自然覆盖
- 复查失败（卡壳/做错）→ 状态回退 🔁，重新进入本周可学池
- 维护方式：状态列直接标 `🔁(7.10)` 这样的日期后缀，周日晚统一扫一遍到期项
- 你有 Anki 习惯的话，把错题和"概念一句话卡"灌入 Anki 代替人工排期更省事

## 七、周检验的变化（相对总纲领第六节的升级）

周日 90 分钟改为：
1. **池盘点（15min）**：数状态——本周各状态净变动（⬜→📖、📖→✍️、✍️→✅、退回🔁各几个）；对照配额与红线缺口
2. **费曼抽讲（25min）**：从本周 ✍️ 新增中随机抽 2 个（数一1个+408一个）讲 10 分钟录音
3. **错题归档（30min）**：不变
4. **复查排期（10min）**：扫🔁到期项，安排进下周
5. **深挖清单（10min）**：处理本周积累

## 八、题量下限的换算（V3两阶段口径）

- **理解期（现在 – 2027.2.10）**：题量下限 = 冒烟测试本身（每点3题，周约60~75题）+ 周日疑点重做。题包不跟随
- **集中刷题期（2027.2中 – 3.31）**：题量下限刚性回位——**每周≥400题**（243个题包约3600题 ÷ 约8周），纯刷题日清12~15包、混合日清6~8包；408算法大题每周✍️≥3道手写
- **强化期起（4月+）**：恢复880/真题口径（数学每周1-2套真题+408分章60~80题），见总纲领

## 九、库存冷启动建议（仅第一周）

完全随机开局会浪费你的依赖检查，第一个星期建议这样开池（之后就纯随机）：
- 数学：M02/M03（极限）或直接 M11（导数，你对导数有物理直觉）；线代可从 L03（矩阵运算，无依赖）随时切入
- 408：D01（复杂度，⚡点，1小时建立信心）→ D02/D03（顺序表/链表）
- 这一批到 📖 后，可学池会自然扩到 30+ 个，随机游走就跑起来了

## 十、维护方式

- **手动版**：直接编辑两份 md 的状态列（每周日集中改，平时学完随手改）
- **Git 版（推荐）**：本目录初始化 git，每次状态变更即一次 commit——状态历史=你的学习行为日志，还能统计"每周真实消耗速率"，下学期校准红线用
- **升级版（以后可做）**：一个本地网页看板（读md渲染池视图/配额仪表/红线进度条）。你需要的时候说一声，半小时给你搭一个

## 十一、吞吐量账本（V3两阶段版·2026-10-06修订）

计划驱动方式：吞吐预测+滚动校准。参数来自你的自评（日5槽）+ V3修订（题包集中）。

**理解期（2026.10 – 2027.02.10，约14周）**
- 日容量：5槽全给新点理解（含每点10min冒烟），复查占用渐增（月1≈0、月2≈0.5、月3起≈1.5~2/天）
- 周产出📖：月1约22~25点、月2约20点、月3约17~18点；期末周3周降档（≈5点/周）
- 累计预算：10月底 ~55 → 11月底 ~145 → 12月底 ~185（含期末损耗）→ 1月底（寒假超车20~23/周）~230 → 2.10收尾到231（95%）
- **红线：2027-02-10 全池📖≥95%、疑点率<15%**

**集中刷题期（2027.02中 – 2027.03.31，约7周）**
- 节奏：每周3个纯刷题日（6~8h，清12~15包）+ 4个混合日（2.5~3.5h刷题，清6~8包）≈ 周35~45包，7周≈250~315包 ✓ 覆盖243
- 顺序建议：按池状态随机清（保持你的随机偏好），但**优先清"冒烟⚠️过的疑点"对应的题包**
- **红线：2027-03-31 全池✍️≥85%、每科≥70%；正确率<50%的模块进4月回炉队列**

**总账对比**：V2同步模式首轮2/28完成；V3两阶段3/31完成✍️——**晚约一个月，换来理解期吞吐20+📖/周（vs 16）与完整心流**；6月首模≥350锚点不动，4-6月强化期仍完整。

**风险结构变化（知情确认）**：V3把"边学边暴露问题的分散小风险"换成"3月集中暴露问题的尾部风险"。对冲=冒烟测试（及时性）+疑点回炉队列（早发现）+4月回炉缓冲月。若3月底发现大面积正确率<50%，4月回炉+5月真题并行，6月首模承压——这是V3的固有代价。

**校准机制（周检验第1步扩展）**：
1. 理解期记录：新📖数 / 冒烟通过率 / ⚠️疑点数
2. 刷题期记录：题包✍️数 / 题量 / 正确率分布（<50%/50-70%/>70%三档）

|---|---|---|---|
| 理解期 | 📖/周 | 11.16校准后仍<15 | 理解期顺延2周，压缩刷题期 |
