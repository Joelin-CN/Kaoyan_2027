# 数学一 · 详细备考计划

> 底数：校内学过已遗忘（按半零基础规划）· 目标125分 · 总预算约1230小时
> 资料主线：武忠祥（基础+强化）→ 1800基础篇 → 880 → 李艳芳真题 → 李林/合工大模拟

## 一、为什么选武忠祥体系（匹配你的学习风格）

武忠祥的特点是**讲概念的来龙去脉和定义的动机**（如极限定义为什么这样写、中值定理怎么构造），不教死套路——与你的溯源式学习高度匹配，且他是数一口碑最稳的老牌名师。李艳芳真题解析是市面上讲解深度最强的真题书，同样匹配。**风险提示：这套组合偏"懂原理"，你需自觉补熟练度，本计划的题量下限就是为此设计。**

概率论推荐余丙森（基础）+方浩（强化）；线代全程李永乐（线代之王，讲义体系完整）。

## 二、阶段任务分解

### P0 基础期（2026.10 – 2027.02，约300h）

**主线：高数（10月-12月中）→ 线代（12月中-2月）**

| 模块 | 内容 | 预计 | 检验标准 |
|---|---|---|---|
| 高数-极限连续 | 武基础课1-6讲+1800对应题 | 3周 | ε-δ语言能自己讲清；等价无穷小替换条件明确 |
| 高数-一元微分 | 导数应用、中值定理 | 4周 | 中值定理三大构造法能默写并各举一例 |
| 高数-一元积分 | 不定积分+定积分+反常积分 | 4周 | 换元/分部类型题一眼分类；几何应用无失误 |
| 高数-多元微分 | 偏导、极值、条件极值 | 3周 | 链式法则树状图能画对 |
| 高数-多元积分 | 二重/三重积分、曲线曲面积分（数一专属难点） | 4周 | 对称性技巧熟练；三类线面积分互相转化条件清晰 |
| 高数-级数+微分方程 | 常数项/幂级数、一阶二阶方程 | 3周 | 收敛域判定流程化；方程类型识别无迟疑 |
| 线代-全程 | 行列式→矩阵→向量组→方程组→特征值→二次型 | 8周 | 李永乐讲义例题全做；相似对角化条件成体系 |

- **周题量下限：≥140题（1800基础篇口径）**；理解慢可以，题量刚性
- 每个模块结束做一次费曼检验（10分钟讲模块主线）
- 高数→线代切换时（12月中），高数进入"每天30min保温"模式（错题重做3道/天），防遗忘曲线

### P1 强化期（2027.03 – 2027.06，约320h）

**主线：概率论基础+高数强化（3-5月）→ 线代强化+真题启动（6月）**

| 任务 | 说明 |
|---|---|
| 概率论基础+强化 | 余丙森基础→方浩强化，4周一轮+2周强化；概率论是三门中"套路最固定"的，目标接近满分章节 |
| 高数强化 | 武忠祥《高等数学辅导讲义》+880高数部分；重点：计算量训练（多元积分和级数是数一失分重灾区） |
| 线代强化 | 李永乐讲义二刷+880线代 |
| 真题启动（6月） | 近15年真题按套拆解（先不掐表）：每周1套，重点做"考点映射"——每道题标注考点模块 |
| 首次全真模拟（2027.06底） | 2023-2025三年真题掐表模拟 → 校准志愿（目标≥340总分） |

- 周题量下限：≥100题/周（880+真题口径）
- 强化期核心转变：**从"学知识"到"考点-题型-方法"三联映射**

### P2 暑期封闭（2027.07 – 2027.08，约240h）

- 真题套卷：2009-2026年真题，**每周2套，上午8:30-11:30严格掐表**
- 每套卷三步走：模拟→批改→错题归因（概念/熟练度/审题）+同类型题补做5道
- 目标：8月底真题卷面≥110，3小时内可完成全卷
- 薄弱模块专项（按错题统计动态确定，通常为：多元积分、级数、线面积分）

### P3 真题期（2027.09 – 2027.10，约200h）

- 真题二刷（只做一刷错误和蒙对的题）+ 李艳芳解析深挖（她的"考源"讲解正是你的菜）
- 每周1套限时模拟维持手感
- 错题本按"错误类型"重组：概念不清类→回讲义；熟练度类→限时刷同类5题

### P4 冲刺期（2027.11 – 2027.12，约170h）

- 李林6+4（11月）、合工大超越卷（12月，难度高于真题用于抗压）
- 每周2套模拟+错题回炉；最后两周回归错题本+基础公式默写
- 考前一周：重做近3年真题保持题感，不碰新难题

## 三、数一专属难点预警（占分高、失分重）

| 难点 | 分值占比 | 对策 |
|---|---|---|
| 多元积分学（重积分+线面积分） | 约20分 | 基础期多给1周；对称性/轮换性技巧专项总结 |
| 无穷级数 | 约10分 | 收敛判定流程图自制；幂级数求和三大类型模板化 |
| 曲线曲面积分（Gauss/Stokes） | 约8分 | 公式记忆用物理意义溯源（流量/环流量）——你的风格适合这么记 |
| 概率大题（分布函数/数字特征） | 约15分 | 套路最固定，强化期保满分训练 |

## 四、风险预案

- **2027.06模拟<100**：策略降级——放弃最难20%题型（如曲面积分技巧题），主攻中低档完备性，目标调至115，总分结构靠408/英语补
- **9月套卷做不完**：启动每日上午严格限时模式，压缩溯源时间盒到30min
- **反复错误率>30%的模块**：停下推进，整模块回炉（讲义重读+课程重看该章节），不欠新账
