# 408 · 详细备考计划

> 底数：四门全零基础（有C/Linux/服务器/数电实战底子）· 目标120分 · 总预算约1040小时
> 主线：王道四件套+王道视频（应试唯一主线）· CSAPP选读作理解加餐（严格时间盒）

## 一、复习顺序与理由

**数据结构 → 计算机组成原理 → 操作系统 → 计算机网络**

1. 数据结构先行：你有C底子，上手最快、正反馈最强，且是全卷分值最大单科（约45分）
2. 计组第二：依赖数据结构理解（指令/机器级），且你有数电基础趁热打铁
3. OS第三：与计组强关联（中断、地址翻译、I/O），你的Linux实操在此发力
4. 网络最后：内容最独立、记忆量最大、放后面离考试近忘得少；你有服务器实战底子

## 二、408试卷结构（2026考纲口径）

| 科目 | 分值 | 题型特点 |
|---|---|---|
| 数据结构 | 45分 | 选择11题+大题2道（含算法设计题，手写代码） |
| 计算机组成 | 45分 | 选择11题+大题2道（数据通路/Cache/指令流水计算题） |
| 操作系统 | 35分 | 选择10题+大题1-2道（PV操作/页面置换/磁盘调度计算） |
| 计算机网络 | 25分 | 选择8题+大题1道（协议分析计算，常结合真实场景） |

**得分策略：选择+计网大题+OS计算题是基本盘（稳定80+）；算法设计题（15-21分）用你的C功底搏高分；计组大题最难，保中档。**

## 三、阶段任务分解

### P0 基础期（2026.10 – 2027.02，约250h）：数据结构+计组

**数据结构（10月-12月中，约140h）**

| 模块 | 重点 | 你的优势/检验 |
|---|---|---|
| 线性表/栈/队列 | 顺序/链式实现、双指针 | C直接手写；一周内能盲写带哨兵的双向循环链表 |
| 树与二叉树 | 遍历（递归+非递归）、线索化、哈夫曼 | 非递归遍历手写是408高频；能讲清三种遍历的栈模拟 |
| 图 | DFS/BFS、最小生成树、最短路、拓扑排序、关键路径 | 手写邻接表+BFS/DFS；Dijkstra/Floyd适用场景对比能讲 |
| 查找 | 二分、BST、AVL、B树、散列 | AVL旋转四种情况图解+手推；散列冲突处理计算题 |
| 排序 | 插入/快排/堆排/归并/基数 | 手写快排+堆排（408算法题考过原题）；各排序复杂度/稳定性表 |
| 算法设计题专项 | 王道课后算法题全做 | 每周至少3道手写代码题，C语言在纸上写（考试是手写！） |

**计组（12月中-2月，约110h）**

| 模块 | 重点 | 你的优势 |
|---|---|---|
| 数据表示 | 补码运算、浮点IEEE754、溢出判断 | **数电底子：组合逻辑这块你几乎白送** |
| 存储系统 | Cache映射（直接/组相联/全相联）、虚存与页表、主存编址计算 | Cache计算题是必考大题，多做画图题 |
| 指令系统 | 寻址方式、CISC/RISC、指令流水线 | 与数据通路联动理解 |
| CPU | 数据通路、微程序控制器、指令执行全流程 | 用"一条指令的一生"费曼串联全书 |
| 总线与I/O | 总线仲裁、中断/DMA/通道 | DMA vs中断对比是高频选择；结合OS的I/O一起学 |

- **周任务刚性**：当周王道章节选择题100%完成+每周3道大题手写
- CSAPP选读窗口：学计组卡壳时读CSAPP第2-3章、第6章（每次≤45min时间盒）
- 真机实验（Linux加成，每模块1次，≤30min）：`gcc -S`看汇编码对应指令系统章节；用C数组越界实验观察内存布局

### P1 强化期（2027.03 – 2027.06，约280h）：OS+网络+前两门二刷

**操作系统（3月-5月初，约150h）**

| 模块 | 重点 | 你的Linux加成 |
|---|---|---|
| 进程管理 | 进程状态机、PV操作（**每年必考大题**）、死锁 | `ps -ef`看状态、用`strace`跟踪系统调用；PV操作用生产者消费者真机感知 |
| 内存管理 | 连续分配、页式/段式、页面置换算法（大题）、虚拟内存 | `free -h`、`/proc/meminfo`、观察缺页（`sar -B`）；页面置换手算LRU/FIFO/CLOCK |
| 文件管理 | FAT/inode、目录、磁盘调度算法计算 | `df`/`du`、`stat`看inode；理解Linux一切皆文件 |
| I/O管理 | I/O层次、缓冲区、设备驱动 | 你调过串口（STM32），中断驱动模型有实感 |

**计算机网络（5月-6月，约90h）**

| 模块 | 重点 | 你的服务器加成 |
|---|---|---|
| 物理层+链路层 | CSMA/CD、以太网帧、滑动窗口 | 帧结构计算题 |
| 网络层 | IP编址/子网划分（**必考计算**）、路由协议、ARP/ICMP | 子网划分刷到条件反射；`traceroute`/`ping`对照ICMP原理 |
| 传输层 | TCP连接管理/拥塞控制/流量控制（**必考大题**）、UDP | **你搭过服务器：三次握手四次挥手在nginx日志里见过SYN_WAIT等状态**；拥塞控制窗口变化手算题专项 |
| 应用层 | HTTP/DNS/FTP/SMTP | HTTP你熟；DNS解析流程结合自己配域名经历记忆 |
| Wireshark实验（1次，1h） | 抓自己部署服务的包看TCP握手+HTTP交互 | 网络层大题的"场景题"语感直接建立 |

- 前两门二刷：数据结构错题+算法题二刷（4-5月每周3h）；计组Cache/数据通路计算题专项
- 6月底：四门首轮完成 + 首次全真模拟（近年真题一套）

### P2 暑期封闭（2027.07 – 2027.08，约210h）

- 真题分章：2009-2026真题按科目拆刷（先按章后成套）
- 大题专项：算法设计题每周4道手写；PV操作、Cache计算、TCP窗口计算各做专项10题
- 简答背诵启动：OS/网络名词解释（每天20min碎片）
- 8月底目标：真题分章正确率>75%，算法题能稳定写出O(n)以上正确解

### P3 真题期（2027.09 – 2027.10，约160h）

- 真题成套掐表（下午14:00-17:00模拟考试时段），每周1-2套
- 错题归因四类：知识缺口（回王道）/ 计算失误 / 审题（场景题长题干）/ 时间不够
- 计组大题策略确认：数据通路题若两轮仍卡，考场策略定位"保小问弃大问"

### P4 冲刺期（2027.11 – 2027.12，约140h）

- 王道8套卷全真模拟（下午场）
- 简答与主观题背诵强化（OS/网络高频简答30题滚动背）
- 算法题手感维持：每两天1道手写
- 考前一周：四科错题本+公式速查表（自制）过两遍

## 四、给你的专属提示

1. **警惕"理解满足感陷阱"**：408的四门课原理都很有趣（尤其OS/计组），你的溯源风格会学得很享受——但408选择题考的是"精确记忆+快速判断"（如各种报文字段、调度算法细节参数），**刷题王道选择题至少2遍是硬指标**，不要用深度理解替代重复刷题。
2. **算法题是你的王牌**：21分的算法设计题对有工程经验的人是送分题（多数考生写不出完整代码），每周手写不能断，纸上写、不查编译器。
3. **真题为王道之上**：王道题质量好但偏难偏怪，真题风格偏基础扎实——9月后一切以真题风格校准，不要被王道模拟题难度带偏心态。
