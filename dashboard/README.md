# 本地看板（dashboard）

零依赖（Python 3.8+ 标准库）。**状态唯一真源 = `data/state.json`**（git 追踪，保存时自动 commit）。

## 启动

- 双击 `start.bat`，或：`python dashboard/server.py`
- 自动打开 `http://127.0.0.1:8787`

## 每日流程（约1分钟决策）

1. **总览**：看进度、距红线天数、吞吐
2. **今日**：选数字 1~5（=今天新点个数）→ 抽取（可"换一批"、复习点±）→ 白天学习
3. **晚间结算**：每个点自评掌握度 1~5 + 冒烟过/未过 + 题包是否清 → 保存（自动 git commit，如 `log: 2026-10-08 新3复习2`）

## 掌握度模型

| 分 | 含义 | 协议符号 | 复查周期 |
|---|---|---|---|
| 1~2 | 薄弱/发现理解错误 | 🔁 | 常驻薄弱池 |
| 3 | 理解（冒烟过） | 📖 | 7天 |
| 4 | 熟练 | ✍️ | 30天 |
| 5 | 精通 | ✅ | 90天 |

- 做题发现理解问题 → 「知识点全表」里直接点低分**降级**，自动回薄弱池
- 复习点抽取排序：mastery 低优先 + 超期越久越优先
- 抽取约束：前置依赖全部📖才可学；新点中A级配额 ≥60%

## 红线口径（总览页对照）

- 理解期红线 2027-02-10：全池📖≥95%、每科≥70%、冒烟疑点率<15%
- 修改红线/周期等参数：`server.py` 顶部常量（REVIEW_CYCLE / REDLINE_UNDERSTAND / AUTO_COMMIT）

## 数据与恢复

- `data/state.json` 损坏 → `git log -- dashboard/data/state.json` 找历史版本恢复
- 知识点定义改动（增删点/改依赖）→ 直接改 `知识点库/*.md` 后**重启服务器**生效（启动时校验总数=243）

## 周日检验

`GET /api/week`（浏览器打开 http://127.0.0.1:8787/api/week ）输出本周吞吐/疑点率，复制进 `03-备考计划/周检验/YYYY-Www.md`。
