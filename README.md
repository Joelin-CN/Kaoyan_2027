## 核心结论（详见 02-决策/择校决策记录.md）

1. **备考科目：数学一 + 英语一 + 408**（政治后置）。不做 816 自控路线，保留上交AI学院/计算机 + 复旦计算机/CIRAM 全部入口。
2. **志愿排序**：
   - 主攻：上交计算机学院 085400（约191人）或 AI学院 085400-02具身智能（约23人，2027新增方向）
   - 稳妥：复旦计算与智能创新学院 085400（约265人，考英二数二408，按11408复习为降维）
   - 博弈位：复旦 CIRAM 01-05 具身方向（苏昊世界模型，但统考仅约6人）
3. **分数目标：初试 410**（数学130 / 408 125 / 英语80 / 政治75；锚定上交AI学院2026录取均分386+通胀与复试容错；2027.06模拟折算<350则回落390结构）。
4. **背景提升**：OpenVLA/π0 复现 + Isaac Lab/MuJoCo 仿真项目 + GitHub，作为复试与联系导师的硬通货。
